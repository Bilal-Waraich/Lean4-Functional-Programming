# Raw Assignments

This directory contains the original homework submission files for the Lean4 Functional Programming course.

Each folder is a self-contained Lean4 project with its own `lakefile.toml` and dependencies:

- `hw01` — Basic Lean4 syntax and definitions
- `hw03` — Inductive types and pattern matching
- `hw04` — Recursive functions and termination
- `hw05` — Monad transformers (State, Throw, Writer stacks)
- `hw07` — Higher-order functions and type classes
- `hw08` — Red-black tree proofs and BST invariants
- `hw09` — Advanced type theory
- `hw10` — Dependent types and propositions

These are preserved as-is from the original submissions. The most interesting implementations have been extracted to `/src`.
